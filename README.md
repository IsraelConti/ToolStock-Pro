# Moments Planner

Aplicación Android independiente para planificar bodas y eventos.

## Funciones

- Selector de modalidad: boda o evento.
- Boda ampliada con pareja, invitados, confirmaciones, menús, mesas y banquete.
- Eventos corporativos, cumpleaños, comuniones, ferias y celebraciones privadas.
- Tareas, responsables, prioridades, fechas y avisos.
- Proveedores, presupuesto, señales, pagos y vencimientos.
- Agenda completa del día.
- Informes Excel y copia de seguridad.
- Navegación hacia atrás en todas las pantallas y botón físico de Android.
- Idiomas, moneda, impuestos y nombre comercial configurables.

## Paquete Android

`com.momentsplanner.events`

La acción `Build Android` genera el APK de prueba y el AAB sin firmar.
